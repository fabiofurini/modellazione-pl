# Laboratorio interattivo

I modelli del corso risolti all'ottimo nel browser: cambia i dati con i cursori o trascinando i punti,
e un simplesso scritto in JavaScript ricalcola la soluzione, con gli stessi numeri degli script Python
e delle dispense. Scegli un'app: si apre a tutta pagina.
